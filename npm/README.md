# usepix

```sh
npm i -g usepix
pix
```

`pix` is [Pi](https://pi.dev), built ahead of time with Bun, with performance patches. It uses Pi's settings, packages
and sessions (`~/.pi`). The first run downloads pix and its Pi for your platform (macOS on Apple silicon, Linux x64 or
ARM64) from the [GitHub release](https://github.com/iamdin/pix/releases), checked against SHA-256 sums.

Without npm: `curl -fsSL https://github.com/iamdin/pix/releases/latest/download/install.sh | sh`. See
https://github.com/iamdin/pix.
